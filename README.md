# vm_labs

## Описание
Лабораторные работы по вычислительной математике. В проекте реализован универсальный фронтенд (на Vue.js), оформленный в виде виртуальных “директорий” — для каждой лабораторной есть отдельная страница в папке `vm_labs` (`lab1`, `lab2`, ...), куда подгружается соответствующее содержимое решения.

## Стек технологий
- **Frontend:** Vue.js, Vite
- **Backend:** Go (отдельный сервис для каждой лабораторной)

## Как запустить

Docker-образов пока нет, запуск вручную.

### Фронтенд

1. Перейдите в директорию:
   ```bash
   cd vm_frontend/vm_frontend
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
   Обычно будет доступен по адресу http://localhost:5173

### Бэкенд

Для каждой лабораторной свой сервер. Запускайте соответствующий:

- Для lab1:
  ```bash
  cd vm_lab1/backend
  go mod download
  go run cmd/server/main.go
  ```
- Для lab2:
  ```bash
  cd vm_lab2/backend
  go mod download
  go run cmd/main.go
  ```
(Для других - аналогично: ищите main.go в соответствующей поддиректории.)

Бэкенд обычно доступен на http://localhost:8080
